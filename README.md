# EliteBnB
EliteBnB is a full-stack MERN web app inspired by Airbnb where users can explore, create, review, and manage property listings. Features include authentication, interactive maps, image uploads, reviews & ratings, CRUD operations, MongoDB Atlas integration, and a fully responsive modern UI.

It is developed using javascript, node.js and express.js

The search functionality and categorisation is yet to be implemented.
